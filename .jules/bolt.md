## 2024-10-13 - [Scalar Extraction & Explicit Casts in Fragment Shader]
**Learning:** In the SoftwareGPU pipeline's hot paths (e.g., shaders), extracting coordinates as standard Python `float` before running `min/max` reduces object overhead. Additionally, casting scalar multipliers to `np.float32()` before multiplying them with NumPy arrays (like colors) prevents silent upcasting to `float64`, which degrades memory usage and math speed in subsequent operations like `np.clip`. Completely replacing NumPy functions like `np.linalg.norm` and `np.clip` with pure scalar equivalents can cause exact byte-parity exact tests to fail, so keeping those exact functions while optimizing the inputs/scalars around them is a safer pattern.
**Action:** Always extract and typecast variables carefully in per-pixel hot paths to prevent silent NumPy promotion while preserving exact test parity functions.
