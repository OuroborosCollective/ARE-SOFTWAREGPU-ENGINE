## 2025-02-23 - [Optimization] Replace np.linalg.norm and np.clip with scalar operations
**Learning:** In the SoftwareGPU pipeline's hot paths (e.g., shaders), replacing Numpy vector operations with standard Python scalar math (`math.sqrt` instead of `np.linalg.norm` and `min`/`max` instead of `np.clip`) for small vectors (3D vectors) is a proven pattern for significantly improving performance. This yielded roughly ~1.44x speedup for shader fragment execution and improved the overall graphics FPS performance geometry tests (load stress score increased).
**Action:** When working in hot loop pipelines processing small arrays, always prefer using scalar Python `math` library functions or simple conditional bounds checking (`min`/`max`) over general purpose Numpy functions which introduce large overhead for small inputs.
