What these results mean

A pass confirms this test image was rendered and read back correctly. Adapter names can be masked by the browser. A CPU or Mesa label does not identify the ARE engine. This add-on does not install a native graphics driver, change Firefox settings or add missing GPU features.

Everything stays in this tab. The add-on sends no diagnostic data, uses no analytics and reads no browsing history. The optional JSON file includes the returned graphics information and pixel buffers; review it before sharing.
